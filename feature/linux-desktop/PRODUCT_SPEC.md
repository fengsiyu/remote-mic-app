# Linux amd64 桌面版产品规范

- 状态：候选实现。协议、配置、音频排空和打包自动化已通过；真实 Ubuntu、BlueZ、PulseAudio/PipeWire、遥控器和目标语音工具尚未验收。
- 适用版本：`0.1.0`。
- 平台附件：[`platform-linux.md`](platform-linux.md)。
- 测试手册：[`Testing/LinuxDesktop.md`](../../Testing/LinuxDesktop.md)。

## 用户问题

现有无线麦 SayAll 只在 macOS 和 Windows 上提供。使用 Ubuntu 桌面的用户无法把兼容的小米蓝牙语音遥控器接入现有语音输入工具，也无法在 Linux 上复用同一套 ATVV 语音会话和基础按键映射。

## 产品目标

为 Ubuntu 20.04 及以上、`amd64` 架构提供可安装的无线麦 SayAll Linux 客户端。用户安装后可以连接 RC001/RC003 兼容遥控器，把遥控器语音写入名为 `SayAll` 的虚拟麦克风，并把遥控器普通按键映射为常用 Linux 输入动作。

## 本次范围

### 提供

- `.deb` 安装包，安装后提供 `sayall-linux` 命令、桌面入口和登录自启动入口。
- 通过 BlueZ D-Bus 发现、配对和连接名称匹配或广播 ATVV Service UUID 的兼容遥控器。
- 接入 ATVV v1.0 及兼容能力，支持 16 kHz IMA ADPCM 语音、同步包、能力协商和麦克风开关命令。
- 自动创建 `SayAll` PulseAudio/PipeWire Pulse 兼容虚拟音源，格式为 16 kHz、单声道、`s16le`。
- 语音键按下立即开始收音，松开后按顺序排空尾音；不使用双击等待窗口或长按阈值。
- 语音期间按住用户配置的语音工具触发键，默认 `F5`，松开语音键时释放。
- 12 个基础按键映射、部分方向键和音量键的按住连发，以及 `0%` 到 `1000%` 输出音量。
- 中文和英文静态界面文案；蓝牙、音频、权限等实时状态当前仍以中文为主，完整状态本地化待后续完善。系统托盘不可用时仍显示普通窗口。
- 有界、脱敏、轮转的运行日志。

### 不提供

- macOS/Windows 的完整设置页、会员功能、常用语、键位方案、按 App 映射、滚动和触摸能力。
- 手机、Apple Watch、网页会话、Onboarding、自动更新、Sentry 或云端服务。
- 自动切换输入法、自动聚焦目标输入框、读取第三方 App 内容或私有数据。
- RC003 长会话的 `MIC_EXTEND` 续租。当前只能按现有 ATVV 会话租期运行，约 60 秒附近的行为必须在真机确认。
- 多只遥控器同时独立路由。当前只维护一个选中的遥控器和一条语音链路。

## 用户可见行为

### 安装与启动

- 安装包名为 `sayall-linux_<版本>_amd64.deb`。
- 安装后用户可从应用菜单启动 `SayAll`，或执行 `sayall-linux`。
- 登录后默认通过 XDG 自启动入口运行，并尽量以状态栏模式启动；没有兼容的状态栏扩展时显示主窗口。
- 应用关闭窗口时，如果状态栏可用则隐藏窗口并继续运行；否则退出进程。

### 遥控器连接

- 用户应先在系统蓝牙设置中完成配对；应用也会对未配对候选发起配对。
- 候选设备必须名称匹配 `MI RC`、`Xiaomi Bluetooth Remote 2`、`Xiaomi Bluetooth Remote 2 Pro`、`小米蓝牙语音遥控器`，或广播包含 ATVV Service UUID。
- 应用优先恢复上次选中的遥控器；用户也可以在页面中选择其他已发现候选。
- 连接后必须完成 Audio/Control 通知订阅和能力读取，界面才显示语音链路就绪。

### 语音输入

- 遥控器语音键按下时，应用立即抓住该按键边沿并按住配置的语音工具触发键，同时等待遥控器 ATVV 音频。
- 目标语音工具必须选择 `SayAll` 麦克风，并把按住说话快捷键配置为同一个触发键，默认 `F5`。
- 遥控器松开语音键后，应用释放触发键，并等待已接收 PCM 按 generation 顺序自然排空。
- 正常结束不得 flush、清空或丢弃仍在途的音频。断连、取消或应用退出只能强制结束，并记录 `completion=forced` 和中断样本数。
- 音频首包延迟记录为 `trigger_down_to_first_pcm_ms`；物理按键到首字的目标工具耗时不能在应用内可靠观察，必须由真机测试补充。

### 普通按键

- 默认映射为：电源 `Esc`、方向键方向键、确定 `Return`、返回 `Backspace`、主页“显示桌面”、菜单“上下文菜单”、TV“切换应用”、音量键系统音量。
- 仅当 `/dev/uinput` 可写且能够独占遥控器输入接口时接管普通按键。权限不足时显示“系统直通”，不得伪造映射成功。
- 按住连发只适用于配置中的方向、返回和音量键；松开或断连必须立即停止。

### 权限与失败

- 缺少 BlueZ、D-Bus、PulseAudio/PipeWire 或 GTK 组件时，界面显示可归因的未就绪原因。
- 缺少输入权限时，语音键按系统原生 `F5` 直通，普通按键不接管。
- 未发现设备、连接失败、能力不支持、蓝牙断开和虚拟麦克风重启失败都必须有独立可见状态。
- 语音会话中不允许重启虚拟麦克风；用户必须等待会话结束后重试。

## 数据与隐私

- 语音 PCM 只存在于进程内存、FIFO 和本机 PulseAudio/PipeWire 音源链路中，不落盘、不上传。
- 配置保存在 `$XDG_CONFIG_HOME/sayall-linux/config.json`，默认 `~/.config/sayall-linux/config.json`，权限为 `0600`。
- 日志保存在 `$XDG_STATE_HOME/sayall-linux/sayall.log`，默认 `~/.local/state/sayall-linux/sayall.log`，单文件上限 1 MiB，超限轮转为 `.1`。
- 日志不得记录语音内容、文字、蓝牙地址、设备身份、文件路径、凭据或第三方 App 私有状态；只记录状态、稳定原因码、计数和耗时。

## 验收边界

- 自动化可以证明协议解析、IMA ADPCM、配置校验、音频 generation 排空和会话状态机。
- 构建和 `.deb` 检查只能证明包结构、依赖声明和 CLI 可加载。
- 真实 BlueZ 配对、GATT 通知、PulseAudio/PipeWire 音源、evdev/uinput 权限、X11/Wayland 输入注入、目标语音工具首字和尾字，必须在 Ubuntu 20.04 及以上 `amd64` 实机完成。
- 在完成上述真机矩阵前，本功能只能称为候选，不得标记为“兼容”“推荐”或“发布候选”。
